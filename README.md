## 🔧 What I Work On

I focus on **Linux DKMS drivers and Wi-Fi support for Amlogic-based set-top boxes** (FiberHome HG680-FJ / ZTE B860H) running **Armbian**.

- 📡 MediaTek **MT7663 / MT7668** SDIO Wi-Fi drivers
- 📶 Realtek **RTL8189FS/FTV** SDIO driver
- ⚙️ Kernel compatibility: Linux **5.10, 6.12, 6.18+ LTS**
- 🛠️ SMP IRQ affinity tuning, RF calibration, 802.11ac support
